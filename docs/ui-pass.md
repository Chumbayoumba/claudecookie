# Дизайн-проход claudecookie

Направление: technical utility, спокойный и доверительный. Не AI-landing и не набор glow-эффектов.

Ограничения, которые нельзя ломать:

- Навигация только plain `<a>`. `connect-src 'self'` режет RSC-роутер Next.
- Вход заголовков — только `transform` (`y`), без `opacity: 0` у H1 и индексного текста. Иначе краулер, который не крутит JS, видит пустой hero.
- `dict.meta.title` / `description` не укорачивать (тест длины).
- Иконки — SVG, не эмодзи.
- Живые cookie из бота и `stats.db` в проверке не использовать.

## Что уже было в коде на момент ТЗ

Privacy в репозитории и на `https://claudecookie.com/privacy/` уже пишет про Яндекс.Метрику. Тег грузится в layout. Противоречие «на сайте нет Метрики» в проде не подтвердилось. Нужно ужесточить две фразы: конвертер не покидает устройство; чекер и credential шифруются в браузере и уходят на бэкенд и в Anthropic.

Анимация Hero есть только у конвертера. `Reveal` на внутренних страницах двигает нижние секции. Шапка `PageHeader` и сами окошки Check / Credential входили статично.

Невалидный результат Check/Credential — красная заливка «This cookie is not valid». Badge Claude Code висел отдельным тегом под формой Credential.

Шапка — плоский ряд из шести ссылок. Футер клал Login Fix и Usage Limits в Tools.

## P0–P8

**P0.** Сверить Privacy с продом. Оставить Метрику как есть, если текст честный. Развести converter / checker одной фразой. Две короткие схемы потока данных.

**P1.** В шапке группа Tools: Convert / Check / Credentials (короткие подписи, filled у текущего). Docs и Guides — выпадающие списки. Privacy отдельно. Мобильное меню теми же блоками. Футер: Tools · Guides · Reference · About. Длинные названия остаются в H1 и meta.

**P2.** Общий вход страницы 280–400 ms, только `y`. Карточки Check и Credential входят так же. Converter Hero не ломать. Swap уже крутится — не дублировать эффект.

**P3.** Невалид — спокойная карточка. Валид — почта, план, две полоски usage. Trust-строки над полем. Меньше простыни на Check, FAQ и howSteps оставить для JSON-LD. Promo на главной — про проверку сессии, не «Also here».

**P4.** Credential: шаги Paste → Verify → Generate. Поведение (ручная проверка, Turnstile, copy/save, sample не конвертировать) не менять. Badge Claude Code в шапку инструмента. Terminal как у Check.

**P5.** JSON formats: матрица сверху, примеры во вкладках. Все четыре примера остаются в DOM.

**P6.** Privacy: две вертикальные схемы.

**P7.** Хлебные крошки вместо одного «Back to the converter». Guides: badge и оглавление по секциям.

**P8.** Лёгкий radial за tool-card, ровные hover/loading. Без новой сетки и шрифтов.
